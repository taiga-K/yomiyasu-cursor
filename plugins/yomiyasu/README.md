# yomiyasu

AIが生成した日本語を、意味と条件を保って読みやすく整える Cursor プラグインです。

このディレクトリがプラグインの本体です。スキルは `skills/yomiyasu/` にあり、リポジトリ直下の [`skills/yomiyasu/`](../../skills/yomiyasu/) と同じファイルです。直下のフォルダが配布用の原本で、こちらは Cursor がプラグインの中から読むための写しです。中身が違っていると CI が失敗します。

呼び方は原本と同じです。依頼に「yomiyasu で」と書くか、`/yomiyasu` と送ります。

入れ方はリポジトリの [README](../../README.md#7-cursor-プラグイン) にあります。
